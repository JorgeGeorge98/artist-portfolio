# Gallery interface palette

The approved turquoise panels anchor the palette. Warm ivory, deep turquoise text and softer blue-grey supporting text give the paintings space; ochre and terracotta provide small artwork-derived accents.

| Role | Hex | Use |
| --- | --- | --- |
| Paper | #FFFAF2 | Canvas background and light surfaces |
| Ink | #1C4149 | Titles, body text, logo and prices |
| Supporting text | #455F66 | Captions, descriptions and metadata |
| Turquoise | #00809E | Main colour reference and interactive outlines |
| Deep turquoise | #00677D | Hover, focus and navigation indicators |
| Ochre | #D0B121 | Logo dot, fine rules and small decorative accents |
| Terracotta | #AE401E | Sold markers and warm pigment accents |
| Sage | #96C6A2 | Artwork-derived supporting pigment |
| Divider | #D5DCD6 | Quiet borders and separators |

## Protected colour sections

The homepage About section, About-page process section and collection gallery invitation retain their approved background **#00809E** and cream text **#FFF3D9**. Their existing gold accents, button colours, hover palette and local tokens are explicitly preserved independently of the rest of the interface.

## Motion and artwork

Only the hero phrase and artist name retain gradients, using blue #11477B, turquoise #007B8C, green #426D57, ochre #8A6D1A and terracotta #AE401E. These deeper pigment tones keep animated lettering legible on ivory. Other headings are static deep turquoise; links rest in deep turquoise and use turquoise interaction states.

Background brushstrokes retain the five colours from the artwork analysis (#96C6A2, #299BA2, #D0B121, #11477B, #AE401E), each with an equal 20% selection probability. Their textures and timing are independent of the interface palette.
